# DockerDemo

A MARS server in a Docker container: the project generated by MARSCmd from `MARSTemplate`, its Linux64 daemon (`DockerDemoServerDaemon`) run in foreground as the main process of an Ubuntu 24.04 container.

| File | What it does |
| --- | --- |
| `Dockerfile` | `ubuntu:24.04` (amd64), the daemon and its ini files in `/app`, a non-root user, `--foreground` |
| `docker-compose.yml` | the same, port 8080, restart policy, the mount of a `Server.ini` with your secrets (commented) |
| `.dockerignore` | only `bin/DockerDemoServerDaemon` and its ini files go in the build context |

## 1. Build the daemon for Linux64

RAD Studio with the Linux64 platform and an Ubuntu SDK (SDK Manager). Open `DockerDemoProjectGroup.groupproj`, select `DockerDemoServerDaemon`, platform **Linux64**, configuration **Release**, and build it: the binary lands in `bin`. From the command line (after `rsvars.bat`):

```bat
msbuild DockerDemoServerDaemon.dproj /t:Build /p:Config=Release /p:Platform=Linux64
```

A PAServer is not needed to build, only the SDK.

## 2. Build and run the image

On the machine with Docker (Docker Desktop on Windows or macOS, Docker on Linux), in this folder:

```bash
docker compose up -d --build
docker compose logs -f
```

or without Compose:

```bash
docker build -t mars-dockerdemo .
docker run -d --name mars-dockerdemo -p 8080:8080 mars-dockerdemo
```

The image is `linux/amd64`, as the binary: on Apple Silicon Docker Desktop runs it through Rosetta.

## 3. Try it

```bash
curl http://localhost:8080/rest/default/helloworld
```

Open `http://localhost:8080/rest/default/openapi` for the OpenAPI document and `http://localhost:8080/rest/default/docs` for its Stoplight Elements page.

`docker compose down` (or `docker stop mars-dockerdemo`) sends `SIGTERM`: the server stops cleanly.

## Secrets

`bin/Server.ini` has no `JWT.Secret`: a Release build refuses to issue and verify tokens without one (a Debug build uses a random one per process). Keep the secret out of the image: copy `bin/Server.ini` to `config/Server.ini` (ignored by git), set `DefaultApp.JWT.Secret` (i.e. `openssl rand -hex 32`) and uncomment the `volumes` of `docker-compose.yml`, or `docker run -v "$PWD/config/Server.ini:/app/Server.ini:ro" ...`.
